# SideQuest IRL MVP outcomes

- [x] **Daily SideQuest home experience** — When the user opens the app, show their level, XP progress, and exactly three safe outdoor quests. Each quest includes an objective, a +30–100 XP reward, and a Start Quest action; the seeded quest set is framed as outdoor activity achievable in 10–60 minutes. Completing a quest updates XP and the current outing.
- [x] **AI Discovery Scanner confidence flow** — The Scan section exposes a camera/photo affordance for plants, flowers, birds, mushrooms, rocks, insects, and other outdoor finds. The Field Guide demo shows common name, scientific name, category, native region, confidence, and Add to Pokédex. The Possible Match state shows ranked candidates with percentages and Try another photo; uncertain identification is never presented as fact.
- [x] **IRL Pokédex collection** — The collection shows total discoveries and category counts. Adding a confident species/object creates one entry; scanning the same species/object again shows Already discovered and awards +5 XP rather than creating a duplicate. The collection uses original SideQuest branding and field-note language.
- [x] **XP and level progression** — The app shows level, explorer rank, XP progress, and feedback for quest completion (+30–100 XP), new discoveries (+50 XP), duplicates (+5 XP), daily challenges (+50 XP), and walking 1 km (+20 XP). Progress is stored in local browser state and level display advances after the MVP threshold.
- [x] **Adventure history and memory** — The Adventures section shows chronological outings with date, distance, duration, discoveries, and completed quests. The home/profile surfaces Adventure Memory context based on interests, past quests, and discoveries. A full map remains deferred beyond v1.
- [x] **PWA delivery and focused scope** — The responsive installable PWA-style experience has Today, Scan, Pokédex, Adventures, and Profile navigation, plus a manifest, icon, service worker, route manifest, durable project logo metadata, and offline-aware shell. No multiplayer, complex RPG combat, social network, full navigation, custom model training, or oversized species database was added.
